## Installation

### Install All Plugins
```bash
# Clone repository
git clone https://github.com/TamerineSky/Agentic-System-Builder.git
cd Agentic-System-Builder

# All plugins are ready to use in plugins/ directory
# Configure Claude Code to load plugins from plugins/ directory
```

### Install Individual Plugin
```bash
# Navigate to plugin directory
cd plugins/revenue-operations  # or any other plugin

# Plugin is ready to use - Claude Code will auto-discover it
```

## Usage Patterns

### For Business Operations Teams
1. **Install domain-specific plugin** (revenue, supply chain, marketing, finance, CS, HR)
2. **Try the quick commands** (e.g., /pipeline-review, /demand-forecast, /campaign-performance)
3. **Leverage agents** for complex analysis and recommendations
4. **Use orchestrations** for multi-step business processes

### For Plugin Creators
1. **Install meta-agent-builder plugin**
2. **Use /generate-plugin** to create custom business plugins
3. **Validate with /validate-plugin** to ensure quality
4. **Optimize with /optimize-plugin** for token efficiency
